学习顺序建议#

  1. 基础阶段（0-2 周）

    • 官方文档 + Tour of Go + Go by Example + 中文视频教程
    • 熟悉语法、变量、切片、数组、map、函数、接口、指针

  2. 进阶阶段（2-4 周）

    • 学习并发（goroutine、channel）、标准库（net/http、os、io 等）
    • Effective Go + Go Web 编程 + Bilibili/GolangCasts 项目实战

  3. 面试准备阶段（4-6 周）

    • 系统做面试题库 + 阅读开源项目 PR / 提交简单 PR
    • 项目实战（REST API + 数据库 + 部署）

  4. 实战与优化阶段（6 周+）

    • 深入理解内存、垃圾回收、接口实现
    • 贡献开源项目、优化性能
    • 部署到 Vercel / GitHub Pages / Docker
