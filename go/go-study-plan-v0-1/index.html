Go v0.1 学习路线图#

本路线图为 tosa 东南亚科技小组 v0.1 基础架构版学习与开发计划，目标是在 4 周内完成可上线的最小可用版本（MVP 基础）。

总进度#

完成度：2 / 16 项
进度条：██░░░░░░░░ 12%
状态：🚀 刚刚开始

学习与开发任务#

第 1 周：Go 基础 + Gin + PostgreSQL#

  • Go 语法：变量、函数、struct、interface
  • 并发编程：goroutine、channel、context
  • Gin 框架：路由、路由分组、中间件
  • PostgreSQL 基础：基本 SQL 语句、查询与插入

第 2 周：数据库工具 + 配置管理 + 日志 + 数据迁移#

  • ORM/代码生成：sqlc 或 Ent
  • 配置管理：Viper（支持多环境配置）
  • 日志：zap（结构化日志）
  • 数据库迁移：golang-migrate（迁移与回滚）

第 3 周：缓存 + 测试 + 中间件#

  • 缓存：go-redis（KV 操作、过期时间、序列化）
  • 单元测试：testify（单测与断言）
  • 中间件：请求日志、Recover、Request-ID、超时控制（context）

第 4 周：容器化 + 部署 + 测试交付#

  • 容器化：Dockerfile（可运行容器）
  • 代码质量：golangci-lint 检查
  • 并发安全测试：go test -race 通过
  • 上线：完成 MVP 基础功能并部署
