Go 学习资源大全#

无论你是刚入门，还是准备进大厂面试，都可以按阶段直接跟着学。

📌 学习顺序建议#

1️⃣ 基础阶段（0-2 周）#

  • 官方文档：Tour of Go + Go by Example
  • 中文视频课程：尚硅谷/黑马/周志明
  • 目标：掌握语法、切片、map、接口、goroutine 基础

2️⃣ 进阶阶段（2-4 周）#

  • Effective Go + 《Go Web 编程》
  • 学习并发、标准库、Web API 项目
  • 目标：能独立完成 Web 服务开发

3️⃣ 面试准备阶段（4-6 周）#

  • 刷面试题库（语法 + 并发 + 数据库）
  • 阅读 gin/kratos 源码，尝试 PR
  • 目标：能自信应对面试技术问题

4️⃣ 实战与优化阶段（6 周+）#

  • 《Go语言高级编程》
  • 学习 GC、内存模型、性能优化
  • 部署项目到 Vercel/GitHub Pages/Docker
  • 目标：具备大厂级别 Go 工程实践能力

💡 小结
这份清单适合从 0 基础到面试冲刺 的学习路线。
建议结合 项目驱动 + 面试题库，边学边做，效果最佳。
