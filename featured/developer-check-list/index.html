核心技能检查清单

2025-08-28 [Updated: 2025-08-28]isme
#Java  #Go  #并发  #Spring  #MyBatis  #Redis  #Kubernetes  #架构  #面试 

核心技能检查清单 ❌🔲🟡✅#

方便清楚的知道自己还差在哪里。

第 0 层：准备与方法#

  • ✅ 选定主力语言顺序：先 Java→Go / 或先 Go→Java（任选一种更熟悉的做主线）
  • 🔲 建立仓库 learning-notes：每个主题一个 README.md，记录要点/坑/例题
  • ✅ 会用以下工具：IDEA / GoLand、VS Code、Postman/curl、Docker、Git & GitHub
  • 🔲 习惯：所有示例都写最小可运行代码 + 单元测试 + 注释为什么

第 1 层：计算机基础（语言无关）#

  • 🟡 操作系统：进程/线程/调度、虚拟内存、页缓存、文件系统、系统调用
  • 🔲 计算机网络：TCP 三次握手/四次挥手、拥塞控制、HTTP/1.1-2-3、TLS、DNS
  • 🟡 数据结构：数组、链表、栈队列、堆、树（AVL/红黑）、Trie、哈希表、图
  • 🔲 算法：排序、二分、前缀和/差分、并查集、DFS/BFS、动态规划
  • ✅ 数据库理论：事务 ACID、隔离级别、索引 B+Tree、执行计划、锁
  • 🔲 分布式基础：CAP、BASE、幂等、重试、限流、熔断、降级、雪崩

第 2 层：Java 基础#

  • ✅ 语法与面向对象：类/接口/抽象类、继承/组合、泛型、异常、注解
  • ✅ 集合：ArrayList / LinkedList / HashMap / TreeMap / ConcurrentHashMap
  • 🟡 IO/NIO：缓冲/通道/选择器、零拷贝、常用 Files/Paths
  • 🔲 JVM：内存结构（堆/栈/元空间）、类加载、字节码基础、JIT、逃逸分析
  • 🔲 GC 算法与实现：Serial/Parallel/CMS/G1/ZGC；Minor/Full GC、调优思路
  • 🟡 并发关键字：synchronized、volatile、final 的可见性与重排序语义
  • 🔲 JUC：AQS、ReentrantLock/StampedLock、CountDownLatch、Semaphore
  • 🔲 线程池：ThreadPoolExecutor 参数、拒绝策略、监控告警
  • 🔲 异步编程：CompletableFuture、（可选）虚拟线程（Java 21）
  • ✅ 常用构建：Maven/Gradle、依赖管理、多模块结构
  • 🔲 单元测试：JUnit 5、Mockito、Testcontainers（集成测试）

第 3 层：Go 基础#

  • 🟡 语法：切片/数组/map、结构体方法、指针/值接收者差异
  • 🔲 接口：隐式实现、io.Reader/Writer、fmt.Stringer
  • 🟡 并发入门：goroutine、channel（无缓冲/有缓冲）、select
  • 🔲 上下文：context.Context 超时/取消/传递元数据
  • 🟡 错误处理：error、errors.Is/As、panic/recover
  • 🟡 工程：go mod、包布局（cmd/internal/pkg）、go test -bench、go vet
  • 🔲 常用库：net/http、encoding/json、time、sync、atomic

第 4 层：并发与多线程#

Java#

  • 🔲 内存模型（JMM）与 happens-before 规则
  • 🟡 锁的选择：对象锁 vs ReentrantLock vs StampedLock
  • 🔲 原子类：Atomic*、LongAdder
  • 🟡 无锁/低锁：CAS、自旋、伪共享与缓存行
  • 🔲 任务编排：线程池 + CompletableFuture 组合
  • 🟡 分布式锁：Redis（SET NX EX、Redisson）、ZK（临时顺序节点）

Go#

  • 🔲 调度模型：G-P-M（M:N）
  • 🔲 Channel 模式：fan-in、fan-out、worker pool、pipeline、背压
  • 🔲 sync：Mutex、RWMutex、WaitGroup、Cond、Once
  • 🔲 性能：避免切片扩容（make(len, cap)）、对象复用（sync.Pool）

第 5 层：数据库与缓存#

  • 🟡 MySQL：索引设计、Explain、覆盖索引、回表、慢查询优化、分库分表思路
  • 🔲 事务与锁：MVCC、快照读/当前读、间隙锁、死锁检测
  • 🟡 Redis：字符串/哈希/列表/集合/有序集合、Bitmap/HyperLogLog/Geo
  • 🔲 Redis 高可用：RDB/AOF、复制、哨兵、Cluster
  • 🔲 缓存模式：Cache Aside / Write Through / Write Back、失效策略
  • 🟡 缓存问题：穿透（布隆过滤器）、击穿（热点互斥）、雪崩（过期错峰）
  • 🔲 分布式锁：正确性（唯一性、原子性、自动过期、可重入/续约）

第 6 层：框架与标准库#

Java（企业后台为主）#

  • 🟡 Spring 核心：IoC、AOP、事件、生命周期、条件装配
  • 🟡 Spring Boot：自动装配、配置映射、Starter 机制
  • 🟡 Web：Spring MVC、校验、全局异常、拦截器/过滤器
  • 🟡 数据访问：MyBatis / MyBatis-Plus、事务、分页、批处理
  • 🟡 Spring Cloud（选型即可）：Nacos/Eureka、OpenFeign、Gateway、Config、Sleuth/Zipkin、Resilience4j

Go（云原生/高并发）#

  • 🔲 Web 框架：Gin/Echo（路由、中间件、绑定与校验）
  • 🔲 ORM：GORM（迁移、事务、预加载、乐观锁）
  • 🔲 依赖注入：Google Wire（编译期 DI）
  • 🔲 配置：Viper；日志：zap/logrus；HTTP 客户端：resty

第 7 层：设计模式与编程思想#

  • 🔲 OOP：封装/继承/多态（Java），组合优于继承（Go）
  • 🟡 必会模式：单例、工厂、策略、装饰器、代理、模板方法、观察者
  • ✅ 反射与动态代理：JDK/CGLIB、AOP 原理（切点/通知/代理链）
  • 🔲 重构：坏味道、提炼函数、引入参数对象、用组合取代继承

第 8 层：工程与架构实践#

  • ✅ Git Flow：feature / release / hotfix
  • ✅ API 设计：REST/JSON、错误码、幂等、版本化
  • 🔲 安全：鉴权（JWT/OAuth2）、CSRF、XSS、SQL 注入、RCE 防护
  • 🔲 日志/指标/追踪：ELK、Prometheus + Grafana、OpenTelemetry
  • 🟡 容器化：Dockerfile 最佳实践、多阶段构建、最小镜像
  • 🔲 编排：Docker Compose → Kubernetes（Pod/Deployment/Service/Ingress）
  • 🔲 配置：ConfigMap/Secret、灰度：HPA/金丝雀/蓝绿
  • ✅ CI/CD：GitHub Actions/Jenkins（构建、测试、镜像、部署）
  • 🔲 云映射：RDS、Elasticache、EKS、S3、CloudFront（或自选云）

第 9 层：源码阅读与开源贡献#

Java#

  • 🔲 JDK：ArrayList、HashMap、ConcurrentHashMap、CompletableFuture
  • 🔲 Spring：IoC/AOP/事务传播、MVC 调度链
  • 🔲 MyBatis：Mapper 动态代理、一级/二级缓存

Go#

  • 🔲 Go runtime：调度、GC 写屏障
  • 🔲 Gin：路由树、Context 设计
  • 🔲 GORM：链式 API、钩子、事务

推荐资料（中文优先）#

  • Java：《Effective Java》《Java 并发编程实战》《深入理解 JVM》
  • Go：《Go 语言圣经》《Go 语言设计与实现》
  • 数据库：《高性能 MySQL》《Redis 设计与实现》（或《Redis 实战》）
  • 架构：《架构整洁之道》《领域驱动设计精要》
  • 云原生：《Kubernetes in Action》《gRPC 官方文档（中文）》

附录：Java 8 → 21 必学特性表#

  • 🟡 Java 8：Lambda / Stream / Optional / 新日期时间 / 默认接口方法
  • 🟡 Java 9-11：模块化、var、HTTP Client、Flight Recorder
  • 🔲 Java 12-17：Switch 新语法、文本块、Records、Sealed Classes
  • 🔲 Java 19-21：虚拟线程（Project Loom）、结构化并发、Scoped Values（了解）
