股票交易所后端程序员学习大纲

2025-09-24 [Updated: 2025-09-24]isme1 分钟 (71 字)
#股票  #交易所  #后端开发  #学习路线  #金融科技 

📚 股票交易所后端程序员学习笔记大纲#

1️⃣ 股票基础概念#

  • 股票是什么、代表什么（股权、份额）
  • 股票种类：普通股 / 优先股 / A股 / B股 / H股 / 美股 ADR
  • 基本术语：市价、现价、涨跌幅、成交量、成交额、股票代码、交易所
  • 流通股、本益比（PE）、市值

2️⃣ 交易规则与流程#

  • 订单类型：限价单、市价单、止损单、止盈单
  • 撮合机制：价格优先、时间优先、订单簿
  • T+1、T+2 规则
  • 交易时间：开盘、收盘、集合竞价、连续竞价
  • 涨跌停板制度

3️⃣ 市场参与者与角色#

  • 投资者（散户、机构）
  • 券商（Broker）
  • 交易所（Exchange）
  • 清算所（Clearing House）
  • 做市商（Market Maker）

4️⃣ 股票数据与行情#

  • Level 1 数据：最新价、成交量、买一卖一
  • Level 2 数据：盘口五档行情
  • K线图：分时、日K、周K、月K
  • 技术指标：均线、MACD、换手率

5️⃣ 清算与结算#

  • 资金账户 / 股票账户
  • 交收周期（T+1 / T+2）
  • 中央结算公司角色
  • 保证金、融资融券、融券卖空

6️⃣ 风控与合规#

  • 风险控制：单笔订单限额、单日交易限额、涨跌停检查
  • 合规检查：KYC、AML、大宗交易报告、异常交易监控

7️⃣ 高级主题（进阶）#

  • 高频交易（HFT）与撮合引擎优化
  • FIX 协议（金融信息交换协议）
  • WebSocket 推送行情 vs REST 接口
  • 低延迟架构、分布式账务系统设计
