MAC系统常用快捷键 基本常用的都整理在这里了

2018-05-31 [Updated: 2018-05-31]isme3 分钟 (436 字)
#MAC  #快捷键  #效率  #MAC快捷键 

写在前面#

Mac 系统中有几个比较特殊的功能键，与 Windows 的差别主要在这里。
比如 Windows 常用的 Ctrl 键，在 Mac 中对应的并不是长得很像的 Control，而是 Command(⌘) 键。
⌘ 几乎是 Mac 上最常用的键。

在 Mac 中，每个按键都有与之对应的 技术符号，常见的有：⌘ ⌥ ⇧ ⌃ ↩︎。
系统菜单和许多技术文章里都用这些符号（虽然我个人觉得直接写 Command 更直观）。

Mac 键盘快捷键符号对照表#

通用操作#

  • ⌘ + Z 撤销
  • ⌘ + X 剪切
  • ⌘ + C 拷贝
  • ⌘ + V 粘贴
  • ⌘ + A 全选
  • ⌘ + S 保存
  • ⌘ + F 查找
  • ⌘ + H 隐藏窗口
  • ⌘ + M 最小化窗口
  • ⌘ + N 新建
  • ⌘ + O 打开
  • ⌘ + ⇧ + S 另存为
  • ⌘ + P 打印
  • ⌘ + W 关闭
  • ⌘ + Q 退出

系统功能#

  • ⌥ 开机 → 启动管理器
  • ⌘ + R 开机 → 恢复模式
  • ⌘ + ⌥ + P + R → 重置 NVRAM
  • ⌘ + ⌥ + ⌃ + ⏏︎ → 退出所有应用并关机
  • ⌘ + ⌥ + ⎋ → 强制退出程序
  • ⌘ + Space → Spotlight 搜索（默认输入法切换，推荐改掉）

截图快捷键#

  • ⌘ + ⇧ + 3 → 全屏截图（保存文件）
  • ⌘ + ⇧ + Ctrl + 3 → 全屏截图到剪贴板
  • ⌘ + ⇧ + 4 → 区域截图，按 Space 捕捉窗口
  • ⌘ + ⇧ + Ctrl + 4 → 区域截图到剪贴板

Finder（文件管理器）#

  • ⌘ + ⇧ + N → 新建文件夹
  • ⌘ + ⇧ + . → 显示/隐藏隐藏文件
  • ⌘ + ⇧ + G → 跳转到路径
  • ↩︎ → 重命名文件
  • ⌘ + O → 打开文件
  • ⌘ + ⌥ + V → 剪切（移动粘贴）
  • ⌘ + ↑ → 打开上级目录
  • ⌘ + ⌫ → 移至废纸篓
  • ⌘ + ⇧ + ⌫ → 清倒废纸篓
  • Space → 快速预览

应用切换#

  • ⌘ + ⇥ → 在应用间切换
  • ⌘ + ⇤ → 反向切换应用
  • ⌘ + ~ → 在同一应用的多个窗口间切换

浏览器快捷键#

  • ⌘ + L → 光标跳至地址栏
  • ⌃ + ⇥ → 下一个标签页
  • ⌃ + ⇤ → 上一个标签页
  • ⌘ + = → 放大页面
  • ⌘ + - → 缩小页面
  • ⌘ + T → 新建标签页
  • ⌘ + W → 关闭标签页

应用程序中#

  • ⌘ + H → 隐藏当前应用
  • ⌘ + ⌥ + H → 隐藏其他应用
  • ⌘ + Q → 退出应用
  • ⌘ + ⇧ + Z → 重做（撤销的逆操作）
  • ⌘ + ⌥ + ⎋ → 打开“强制退出”窗口

文本处理#

  • ⌘ + B → 粗体
  • fn + Delete → 向后删除
  • fn + ↑ / ↓ / ← / → → Page Up / Page Down / Home / End
  • ⌘ + ← → 光标到行首
  • ⌘ + → → 光标到行尾
  • ⌘ + ↑ → 光标到文稿开头
  • ⌘ + ↓ → 光标到文稿结尾
  • ⌥ + ← → 光标到上一个单词开头
  • ⌥ + → → 光标到下一个单词末尾
  • ⌃ + A → 行首/段落开头

总结#

Mac 快捷键逻辑简单：⌘ 相当于 Ctrl，fn+方向键 用来模拟 PC 的 Page Up/Down/Home/End。
熟练掌握这些快捷键能大幅提升效率 🚀。
