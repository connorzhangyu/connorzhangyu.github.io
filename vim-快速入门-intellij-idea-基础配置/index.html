Vim 快速入门 & IntelliJ IDEA 基础配置

2025-08-13 [Updated: 2025-08-13]isme2 分钟 (234 字)
#Vim  #IdeaVim  #IntelliJ IDEA  #快捷键  #配置 

前言#

Vim 是一款强大的编辑器，配合 IntelliJ IDEA 的 IdeaVim 插件，可以显著提升代码编辑效率。本文将介绍 Vim 最小必备快捷键 以及 IdeaVim 的基础配置方法，帮助你快速上手。

一、Vim 最少必备快捷键（初学者版）#

1. 移动（6 个）#

功能按键
光标左 / 右h / l
光标上 / 下k / j
行首 / 行尾0 / $
文件开头 / 结尾gg / G

2. 编辑（7 个）#

功能按键
插入模式（前 / 后）i / a
新行（下 / 上）o / O
删除当前行dd
复制当前行yy
粘贴到光标后p
撤销u

3. 查找（2 个）#

功能按键
搜索字符串（向下）/关键字
下一个匹配n

💡 记忆技巧：

  • 移动全靠 hjkl（左下上右）+ 0 和 $（行首行尾）
  • 编辑记住 i（insert）a（append）o（open new line）d（delete）y（yank）p（paste）u（undo）
  • 查找只记 / 和 n

二、在 IntelliJ IDEA 中启用 Vim#

  1. 打开 Preferences → Plugins，搜索并安装 IdeaVim 插件。
  2. 重启 IntelliJ IDEA。
  3. 底部状态栏会出现 VIM 图标，表示插件已启用。

三、配置 IdeaVim 基础功能#

1. 创建 ~/.ideavimrc#

IdeaVim 支持读取 ~/.ideavimrc 作为配置文件（类似 .vimrc）。
在终端创建：

1

touch ~/.ideavimrc

2. 示例配置#

下面是一个适合初学者的 .ideavimrc 示例：

 4
 5
 6
 7
 8
 9
10

" 显示行号
set number
set relativenumber

" 系统剪贴板互通
set clipboard+=unnamedplus

" 普通模式下自动切换到英文输入法（需 IdeaVimExtension + im-select）
set keep-english-in-normal

" 保存文件快捷键：空格 + w
map <Space>w :w<CR>

3. 自动切换英文输入法（可选）#

如果中文输入法会干扰 Vim 按键，可以：

  1. 安装 IdeaVimExtension 插件（在 IDEA 插件市场）。

  2. 安装 im-select 工具。

  3. 在 ~/.ideavimrc 中加入：

    1

    set keep-english-in-normal

这样每次 Esc 回到 Normal 模式时，会自动切到英文输入法。

四、常见问题#

1. G 快捷键无效#

  • 先按 Esc 确保在 Normal 模式。
  • 切换到英文输入法再按 Shift + g。
  • 如果仍无效，执行 :verbose map G 检查是否被映射覆盖。

2. .ideavimrc 修改不生效#

  • 重启 IntelliJ IDEA。

  • 或在 IDEA 中执行：

    :source ~/.ideavimrc

五、总结#

  • 先掌握最小快捷键（15 个左右），保证能替代鼠标完成基本编辑。
  • 在 IDEA 配置 .ideavimrc，提升编辑体验。
  • 建议配合自动切英文功能，消除输入法干扰。

掌握这些内容后，你的代码编辑效率会有明显提升。

如果你已经学会这些基础操作，可以逐步学习更高级的 Vim 功能，例如文本对象（ci"、di( 等）、多文件编辑、宏录制等，让 Vim 真正成为你手中的利器。
