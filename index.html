📖 Neovim / Neovide 常用操作宝典#

🔹 模式切换#

模式进入方式说明
普通模式 (Normal)Esc默认模式，用来移动/复制/删除
插入模式 (Insert)i → 光标前插入
a → 光标后插入
o → 下一行新建插入		写代码/文字
命令模式 (Command):执行命令，如保存、退出

🔹 移动光标#

操作命令说明
上/下/左/右k j h l方向键替代
单词前进/后退w / b跳到单词开头
行首/行尾0 / $
文件开头/结尾gg / G
跳到指定行:N例如 :20 跳到第 20 行

🔹 编辑文本#

操作命令说明
删除一行dd
删除单词dw
撤销u
重做Ctrl-r
复制一行yy
粘贴p光标后粘贴
替换字符r单个字符替换
全选并删除ggVGd

🔹 搜索与替换#

操作命令说明
搜索单词/wordn → 下一个，N → 上一个
替换（当前行）:s/foo/bar/替换第一个 foo
替换（整行所有）:s/foo/bar/g
替换全文:%s/foo/bar/g

🔹 文件操作#

操作命令说明
保存:w
另存为:w filename
退出:q
强制退出:q!
保存并退出:wq 或 ZZ

🔹 窗口 / 标签页#

操作命令说明
分屏（水平）:sp filename
分屏（垂直）:vsp filename
切换窗口Ctrl-w h/j/k/l类似 tmux
新建标签页:tabnew
下/上一个标签gt / gT
关闭当前标签:tabclose

🔹 插件常用（基于推荐配置）#

操作命令说明
打开文件树<Space>envim-tree
切换标签<S-h> / <S-l>bufferline
跳到第 N 个文件<Space>1..9bufferline
打开 Markdown 预览<Space>mpmarkdown-preview.nvim

🔹 终极组合（写代码常用）#

  • 快速移动：w b 0 $ gg G
  • 增删改查：yy dd p u Ctrl-r /word
  • 工程管理：<Space>e（文件树），:wq（保存退出）
  • Markdown 写博客：<Space>mp 开预览
