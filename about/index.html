📝 版本记录

这个版本更新的过程正是一个学习的过程。
所以请不要好奇，为什么这么简单的一坨屎也要一直在上面雕花。

v1

  • 1.0 采用 Halo 部署到个人服务器，使用域名商 DNS 解析到服务器。

v2

  • 2.0 框架调整 改用 Hexo。
  • 2.1 迁移至 GitHub Pages（官方部署方式）。
  • 2.2 源码分库。
  • 2.3 部署方式改为 GitHub Actions 工作流。
  • 2.4 加入 Cloudflare 转发。

v3

  • 3.0 框架调整 改用 Hugo。
  • 3.1 扩展 Vercel 部署，双发双域名。
  • 3.1（优化） 改为单域名，使用 Cloudflare Worker 做主备回源，隐藏子域。
  • 3.2 扩展 Cloudflare 部署，实现“一建三发，一主两备”。
  • 3.3 增加备用域名转发规则，路由至主域名。
  • 3.3（优化） Worker 调整：停用子域，直接回源源站地址。
  • 3.4 优化多域名转发，停用 CF 规则，启用 Worker。
  • 3.5 工作流优化 增加合并检查项 构建检查 以及 md格式检查。
  • 3.5 增加 makefile 增加本地构建检查。
