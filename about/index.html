关于我 🤔

你好，朋友！欢迎来到我在互联网的这个小角落。

我的理念 💡

Don’t you have some B number in your heart?

这是我的人生座右铭。换成更正式的说法可能是：
“你真棒”

我是谁？ 🐼

  • 一个写 Java 和 Go 的 牛马，有时跟电脑说话比跟人多。
  • 一个 全栈探索者 —— 后端、前端、云，都能掺到我的咖啡里。
  • 一个 不折腾会难受的人。
  • 天生好奇，偶尔毒舌，长期咖啡因驱动。

我的信条 📜

  1. 代码能跑就别动……除非它不跑了。
  2. 文档就像蔬菜 —— 对你有好处，但总容易忘记吃。
  3. 截止日期是弹性的，bug 是永恒的。
  4. 永远要心里有点数 —— 不管对你来说意味着什么。

联系我 📬

如果你想聊聊技术、生活，或者只是分享点有意思的话，
你可以在代码里、提交记录间，或者咖啡馆里找到我。
